# Component Color Reference — Light Mode

Quick lookup for exact class values per component in light mode.

## Core Palette
```
primary   = #3DB54A  brand green
secondary = #1A5BB6  brand blue
accent    = #00A99D  brand teal
node      = #7B5EA7  purple (≤2 elements per page)
cyan      = #00C8CC  bright cyan (glow highlights only)

Backgrounds:
  white    = #FFFFFF
  soft     = #F0FAF1  (faint green-white, alternate sections)
  teal-bg  = #F0FFFE  (faint teal-white, workflows section)
  footer   = #F9FAFB  (gray-50)

Text:
  heading  = #111827  (gray-900)
  body     = #374151  (gray-700)
  muted    = #6B7280  (gray-500)
  subtle   = #9CA3AF  (gray-400)
```
